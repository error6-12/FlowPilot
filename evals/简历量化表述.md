# 简历量化表述（2026-09-22 实测版）

## 建议放入项目经历

- 构建企业内部流程 Multi-Agent 平台，以结构化路由协调知识咨询与请假、报销、IT 工单、资源预订等 Workflow Agent；修复规则咨询误路由后，在同一组 60 条口语、省略和歧义测试集上准确率由 96.7% 提升至 98.3%。
- 接入企业私有知识库与 FAISS 语义检索，在 35 条知识问答评测集上实现 Hit Rate@5 100%、MRR 0.945，平均检索延迟 398ms。
- 将多轮语义抽取与确定性状态机、SQLite 审计持久化解耦，引入终态幂等保护后，24 组字段补充、纠正、取消与跨意图任务通过数由 23 组提升至 24 组；20 条端到端回放均正常结束。
- 建立可复现评测脚本，逐条记录路由、检索排名、流程字段、平均/P95 延迟与 Token；当前实测路由平均 862 Token/请求、Workflow 平均 1193 Token/轮。

## 面试时必须说明

- 这些是固定开发评测集结果，样本量分别为 60、35、24 和 20，不代表生产流量 SLA。
- 当前 Agent 项目使用的是 Dense Embedding + FAISS，不应描述为已经实现 Hybrid Search、BM25、RRF 或 Reranker。
- 已保存同一测试集、同一模型配置下的优化前后报告，可引用路由和 Workflow 的提升；路由 Prompt 变长后 Token 有所增加，因此不能宣称整体 Token 降低。
- 通用 Tool Registry/MCP 执行闭环尚未完成，暂不写“工具调用成功率”。
