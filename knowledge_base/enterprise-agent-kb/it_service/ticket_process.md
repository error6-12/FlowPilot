## 工单提交流程

### 1. 自助提交
1. 登录 OA系统（https://oa.company.com）
2. 进入 "IT服务" → "新建工单"
3. 选择工单类型
4. 填写详细信息：
   - **问题描述**：清晰描述故障现象
   - **设备编号**：资产标签上的编号
   - **所在位置**：楼层/工位号
   - **联系方式**：手机号/企业微信
   - **截图/照片**：如有错误提示请截图上传
5. 设置优先级（系统会建议，可调整）
6. 提交工单

### 2. 电话报修
- **IT热线**：拨打分机 8888
- **服务时间**：
  - 工作日 9:00-18:00：全类型支持
  - 非工作时间：仅处理P1级紧急故障
- **报修信息准备**：
  - 工号、姓名
  - 问题描述
  - 设备位置和编号
  - 联系电话

### 3. 企业微信报修
- 在"IT服务"企业微信群发送消息
- @IT值班人员
- 描述问题并附上截图
- IT人员会协助创建工单

## 工单处理流程

### 标准处理流程
```
1. 工单创建 → 2. 自动分配 → 3. IT接单 → 4. 诊断处理 → 5. 解决/升级 → 6. 用户确认 → 7. 工单关闭
```

### 各步骤说明

#### 1. 工单创建
- 通过OA、电话、企业微信创建
- 系统自动生成工单号：IT-YYYYMMDD-XXX

#### 2. 自动分配
- **按类型分配**：硬件→硬件组、网络→网络组、账号→系统组
- **按区域分配**：3楼→A组、5楼→B组、8楼→C组
- **按优先级分配**：P1直接分配给高级工程师

#### 3. IT接单
- IT工程师在系统中接单
- 系统自动通知报修人："您的工单已被XXX接单"

#### 4. 诊断处理
- **远程处理**：通过远程桌面诊断和修复
- **现场处理**：到工位现场排查
- **送修处理**：设备需带回IT维修间

#### 5. 解决/升级
- **解决**：记录解决方案，更新工单状态
- **升级**：无法解决时升级至高级工程师或外部供应商

#### 6. 用户确认
- IT标记"已解决"后，系统通知报修人确认
- 报修人在48小时内确认解决
- 未确认则自动关闭工单

#### 7. 工单关闭
- 用户确认解决 → 工单关闭
- 用户不满意 → 重新打开，重新分配

## 工单优先级说明

### P0 - 系统级故障
- **定义**：影响全公司或某楼层的网络/系统瘫痪
- **响应**：5分钟内
- **处理**：IT全员响应，启动应急预案
- **示例**：核心网络中断、服务器宕机、邮件系统瘫痪

### P1 - 紧急
- **定义**：影响个人正常工作，无法绕过
- **响应**：15-30分钟
- **处理**：优先处理，必要时备用机替代
- **示例**：电脑无法开机、账号锁定、断网

### P2 - 高
- **定义**：影响工作效率，但有临时替代方案
- **响应**：1-2小时
- **处理**：尽快处理
- **示例**：网速慢、软件报错、外设故障

### P3 - 中
- **定义**：不影响核心工作，属于便利性需求
- **响应**：4小时
- **处理**：按序处理
- **示例**：软件安装、非关键设备故障、权限申请

## 工单查询

### 查询方式
1. **OA系统**：IT服务 → 我的工单
2. **企业微信**：IT服务机器人 → 工单查询
3. **电话查询**：拨打8888，报工单号查询

### 可查询信息
- 工单状态（待处理/处理中/已解决/已关闭）
- 处理人员
- 处理进度
- 预计完成时间

## 满意度评价

### 评价维度
- **响应速度**：IT接单是否及时
- **解决效果**：问题是否彻底解决
- **服务态度**：IT工程师沟通是否友好
- **专业知识**：IT工程师是否专业

### 评价方式
- 工单关闭后系统推送评价链接
- 企业微信推送评价卡片
- 评价结果纳入IT部门KPI

## 常见问题FAQ

### Q1: 提交工单后多久有人处理？
**A**: P1级工单15分钟内响应，P2级1小时内响应，P3级4小时内响应。

### Q2: 工单处理太慢可以催单吗？
**A**: 可以。在企业微信IT服务群@IT主管，或拨打8888说明工单号，会有专人跟进。

### Q3: 工单被退回怎么办？
**A**: 查看退回原因（通常备注在工单中），补充信息后重新提交。常见原因：信息不完整、非IT问题、需联系其他部门。

### Q4: 下班后电脑坏了怎么办？
**A**: 拨打IT热线8888，非工作时间仅处理P1级紧急故障。非紧急可次日提交工单。

### Q5: IT可以远程处理吗？
**A**: 软件问题、配置问题可以远程处理，需您授权远程连接。硬件问题需现场处理。

### Q6: 电脑需要送修多久能拿回来？
**A**: 简单故障当天取回，需要更换配件的1-3个工作日，需要送外部维修的3-7个工作日。
