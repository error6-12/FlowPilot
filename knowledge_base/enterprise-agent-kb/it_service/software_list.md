## 六、软件申请流程

### 6.1 免费软件
1. 联系IT热线（分机8888）
2. 说明软件名称和用途
3. IT工程师远程或上门安装

### 6.2 付费软件
1. 登录OA系统 → 软件申请
2. 填写软件名称、版本、用途、申请理由
3. 部门负责人审批
4. IT部门评估（1个工作日）
5. 采购/分配授权
6. IT安装部署

### 6.3 特殊软件
- **开发工具License**：由技术负责人统一申请
- **设计工具License**：由设计部门负责人统一申请
- **跨部门共用**：由使用频率最高的部门申请

## 七、软件使用规范

### 7.1 允许安装的软件
- 办公软件
- 开发工具（经审批）
- 设计工具（经审批）
- 公司指定的安全软件

### 7.2 禁止安装的软件
- 游戏软件
- 盗版软件
- 未经授权的云存储（个人网盘）
- P2P下载工具
- 远程控制软件（非公司指定）
- 挖矿软件

### 7.3 违规处理
- **首次违规**：警告并要求卸载
- **再次违规**：通报批评，扣除绩效
- **严重违规**（如安装盗版造成法律风险）：解除劳动合同
