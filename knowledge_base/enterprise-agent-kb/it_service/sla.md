# IT服务等级协议（SLA）

## 服务概述

IT部门承诺为公司全体员工提供高效、可靠的IT服务。本SLA定义了服务标准、响应时间、解决时间和各方责任。

## 服务范围

### 包含服务
- 硬件设备维护（电脑、显示器、打印机、外设等）
- 网络服务（有线网络、WiFi、VPN等）
- 软件服务（办公软件、开发工具、业务系统）
- 账号与权限管理
- 信息安全服务
- 数据备份与恢复
- IT咨询服务

### 不包含服务
- 个人设备维修
- 个人软件安装（非工作相关）
- 个人数据恢复（非公司数据）
- 非工作时间的非紧急服务

## 服务等级定义

### 等级一：P0 - 系统级故障
| 项目 | 标准 |
|------|------|
| 定义 | 影响全公司或某楼层/部门的系统性故障 |
| 示例 | 核心网络中断、邮件系统瘫痪、服务器宕机、OA系统崩溃 |
| 响应时间 | 5分钟内 |
| 解决时间 | 2小时内 |
| 升级机制 | 直接通知IT总监，必要时启动应急预案 |
| 通报机制 | 每30分钟更新进展，企业微信全员通知 |

### 等级二：P1 - 紧急
| 项目 | 标准 |
|------|------|
| 定义 | 影响个人正常工作，无法绕过继续工作 |
| 示例 | 电脑无法开机、账号被锁定、断网、蓝屏死机 |
| 响应时间 | 15分钟内 |
| 解决时间 | 4小时内 |
| 升级机制 | 30分钟未解决升级至IT主管 |
| 替代方案 | 必要时提供备用设备 |

### 等级三：P2 - 高
| 项目 | 标准 |
|------|------|
| 定义 | 影响工作效率，但有临时替代方案 |
| 示例 | 网速慢、打印机故障、软件报错、显示器异常 |
| 响应时间 | 1小时内 |
| 解决时间 | 8小时内（1个工作日） |
| 升级机制 | 4小时未解决升级至IT主管 |

### 等级四：P3 - 中
| 项目 | 标准 |
|------|------|
| 定义 | 不影响核心工作，属于便利性需求 |
| 示例 | 软件安装、权限申请、非关键外设故障、配置变更 |
| 响应时间 | 4小时内 |
| 解决时间 | 24小时内（1-2个工作日） |
| 升级机制 | 24小时未解决升级至IT主管 |

## 服务时间

### 正常服务时间
| 时段 | 服务内容 | 响应方式 |
|------|---------|---------|
| 工作日 9:00-18:00 | 全类型IT服务 | 现场+远程 |
| 工作日 18:00-21:00 | P0/P1级服务 | 远程优先 |
| 工作日 21:00-次日9:00 | P0级服务 | 仅远程 |
| 周末/节假日 | P0级服务 | 仅远程 |

### 特殊支持
- **重大项目上线**：可申请IT值班保障（提前3天申请）
- **紧急出差**：可拨打IT热线8888获取远程支持

## 各方责任

### IT部门责任
- 按SLA标准响应和处理工单
- 定期巡检和维护IT基础设施
- 及时通报系统故障和恢复进展
- 记录和处理所有IT工单
- 持续改进服务质量

### 用户责任
- 提供清晰、完整的问题描述
- 配合IT工程师排查问题（远程连接、现场访问）
- 遵守信息安全规范
- 及时反馈问题处理结果
- 工单关闭后48小时内确认

### 管理层责任
- 支持IT部门资源投入
- 审批重大IT投资决策
- 推动IT制度落地执行

## 服务报告

### 月度报告
- 每月初发布上月IT服务报告
- 内容包括：工单统计、SLA达标率、满意度、重大事件回顾
- 发布渠道：OA公告 + 企业微信群

### 季度评审
- 每季度进行SLA评审会议
- 参会方：IT部门、各部门代表
- 内容：SLA达标分析、问题改进、下季度计划

## 升级与投诉

### 升级路径
```
IT工程师 → IT主管 → IT经理 → IT总监 → CTO
```

### 投诉渠道
| 渠道 | 方式 | 处理时限 |
|------|------|---------|
| 企业微信 | @IT主管 | 24小时内 |
| 邮件 | it-complaint@company.com | 24小时内 |
| 电话 | 拨打8888转投诉 | 即时 |
| OA系统 | "IT投诉"入口 | 48小时内 |

### 投诉处理流程
```
投诉提交 → 受理确认（24小时） → 调查分析 → 处理方案 → 结果反馈 → 满意度回访
```

## 免责条款

### IT部门免责情况
- 不可抗力（自然灾害、电力中断、运营商故障等）
- 用户自身操作不当导致的问题
- 用户私自安装软件造成的故障
- 用户未配合排查导致延误
- 非工作时间非紧急需求的合理延迟
- 第三方系统故障（SaaS服务商等）

## 常见问题FAQ

### Q1: 什么算"响应"？
**A**: IT工程师接单并首次联系报修人即为响应。可能是电话、企业微信消息或远程连接请求。

### Q2: 解决时间包含等待配件的时间吗？
**A**: 常规配件包含在内。如需特殊配件或外部采购，IT会告知预计时间，此段时间不计入SLA。

### Q3: SLA不达标怎么办？
**A**: IT部门需提交改进方案，连续2个月不达标将启动专项整改。用户如受影响可通过投诉渠道反馈。

### Q4: 如何评价IT服务质量？
**A**: 每个工单关闭后会推送满意度评价。评价匿名处理，结果纳入IT部门绩效考核。

### Q5: 夜间或周末有IT支持吗？
**A**: 夜间和周末仅支持P0级系统故障。P1级可远程支持，其他问题建议工作日提交。

### Q6: 对IT服务不满意怎么反馈？
**A**: 可通过企业微信@IT主管、发邮件到it-complaint@company.com，或在OA系统"IT投诉"入口提交。投诉会在24小时内受理。
