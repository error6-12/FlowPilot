# IT服务常见问题FAQ

## 账号与权限

### Q1: 忘记密码怎么办？
**A**: 
- **自助重置**：访问 https://password.company.com，使用手机号或邮箱验证身份后自助重置
- **联系IT**：拨打IT热线 8888 或提交工单，提供工号和身份信息验证
- **处理时间**：自助重置即时生效；IT协助处理需30分钟内

### Q2: 如何申请系统权限？
**A**:
- 登录OA系统 → 权限申请 → 选择系统和权限级别
- 填写申请理由，经部门负责人审批
- IT部门在1个工作日内开通
- 特殊权限（如财务系统、数据库）需额外审批

### Q3: 新员工什么时候能获得账号？
**A**:
- HR完成入职手续后，IT会在入职当天开通：
  - 企业邮箱
  - OA系统账号
  - VPN账号（如需要）
  - 即时通讯账号
- 其他系统权限由部门负责人在入职后3天内申请

### Q4: 邮箱容量满了怎么办？
**A**:
- 企业邮箱容量：5GB
- 清理建议：删除大附件邮件、归档历史邮件到本地
- 扩容申请：提交IT工单，说明需求，IT评估后可扩容至10GB

## 网络与连接

### Q5: 无法连接公司WiFi怎么办？
**A**:
- **WiFi名称**：Company-WiFi（员工）、Company-Guest（访客）
- **连接方式**：使用域账号和密码登录
- **故障排查**：
  1. 确认账号密码正确（区分大小写）
  2. 重启设备WiFi功能
  3. 忘记网络后重新连接
  4. 联系IT热线 8888

### Q6: VPN无法连接怎么办？
**A**:
- **适用场景**：远程办公、出差访问内网
- **连接方式**：使用公司VPN客户端（官网下载）
- **常见问题**：
  - 密码错误：确认使用的是域账号密码
  - 证书过期：联系IT更新证书
  - 客户端版本过旧：更新到最新版本
- **处理时间**：IT在30分钟内响应

### Q7: 网速很慢怎么办？
**A**:
- 确认是否为个别网站慢还是全部慢
- 尝试切换WiFi或有线网络
- 联系IT排查，提供具体位置和时间
- 高峰期（10:00-11:00、14:00-15:00）可能有短暂拥堵

### Q11: 如何申请新电脑？
**A**:
- **申请条件**：
  - 电脑使用满3年
  - 频繁故障，维修成本过高
  - 岗位变动需要更高配置
- **申请流程**：
  1. OA提交《设备更换申请》
  2. IT评估（1个工作日）
  3. 部门负责人审批
  4. IT采购/分配新设备（3-5个工作日）
- **配置标准**：
  - 普通办公：i5/16G/512G SSD
  - 开发人员：i7/32G/1T SSD
  - 设计人员：i7/32G/1T SSD + 独立显卡

## 安全与合规

### Q12: 如何防范钓鱼邮件？
**A**:
- **识别特征**：
  - 发件人地址异常（如company@compny.com）
  - 要求点击链接或下载附件
  - 索要账号密码或敏感信息
  - 语气紧急或威胁性
- **处理方式**：
  - 不要点击链接或下载附件
  - 立即删除邮件
  - 向IT部门举报（转发至phishing@company.com）

### Q13: 可以使用个人U盘吗？
**A**:
- **原则上禁止**：防止数据泄露和病毒传播
- **特殊需求**：
  - 提交OA申请，说明用途和文件类型
  - 使用公司加密U盘（IT发放）
  - 使用前杀毒扫描
- **替代方案**：使用企业云盘传输文件

### Q14: 发现电脑中毒怎么办？
**A**:
- **立即断网**：拔掉网线或关闭WiFi
- **不要重启**：防止病毒扩散
- **立即报告**：拨打IT热线 8888
- IT工程师会在30分钟内处理
- 配合IT进行病毒查杀和数据恢复
