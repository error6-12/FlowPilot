# 报销政策

## 适用范围
本政策适用于公司全体员工因公产生的费用报销，包括差旅费、招待费、交通费、办公用品等。

## 报销类别与标准

### 1. 差旅费报销

#### 1.1 交通费标准
| 职级 | 飞机 | 高铁/动车 | 火车 | 轮船 |
|------|------|----------|------|------|
| 高管（VP及以上） | 商务舱 | 一等座 | 软卧 | 一等舱 |
| 总监/高级经理 | 经济舱 | 一等座 | 软卧 | 二等舱 |
| 经理/主管 | 经济舱 | 二等座 | 硬卧 | 二等舱 |
| 普通员工 | 经济舱 | 二等座 | 硬卧/硬座 | 三等舱 |

#### 1.2 住宿标准（元/晚）
| 城市等级 | 高管 | 总监/高级经理 | 经理/主管 | 普通员工 |
|---------|------|-------------|----------|---------|
| 一线城市（北上广深） | 实报实销 | 800 | 600 | 500 |
| 二线城市（省会等） | 实报实销 | 600 | 500 | 400 |
| 三线及以下城市 | 实报实销 | 500 | 400 | 300 |
| 海外（欧美日澳） | 实报实销 | 2000 | 1500 | 1200 |
| 海外（东南亚等） | 实报实销 | 1000 | 800 | 600 |

**说明**：
- 一线城市：北京、上海、广州、深圳
- 二线城市：杭州、南京、成都、武汉、西安、重庆等省会及经济发达城市
- 超标住宿需提前申请并经部门负责人和财务审批

#### 1.3 餐饮补贴（元/天）
| 城市等级 | 标准 |
|---------|------|
| 一线城市 | 100 |
| 二线城市 | 80 |
| 三线及以下 | 60 |
| 海外 | 150（折合人民币） |

**说明**：
- 餐饮补贴为包干制，无需提供发票
- 出差当天按实际出发/返回时间计算
- 招待客户期间的餐饮费不计入个人补贴

#### 1.4 市内交通
- **实报实销**：出租车、网约车、地铁、公交
- **私车公用**：按0.8元/公里补贴（含油费、过路费）
- **限额**：一线城市每日不超过200元，其他城市不超过150元

### 2. 业务招待费

#### 2.1 招待标准（元/人/次）
| 招待对象 | 标准 |
|---------|------|
| 重要客户/政府官员 | 500 |
| 一般客户/合作伙伴 | 300 |
| 内部跨部门 | 150 |

#### 2.2 招待费报销要求
- 必须提前申请，填写《业务招待申请单》
- 招待人数：我方人员不超过客方人数的1/2
- 需提供：发票、消费明细、招待事由、参与人员名单
- 超标需提前经VP级领导审批

### 3. 办公用品报销
- **个人申领**：单次不超过500元，由部门负责人审批
- **部门采购**：超过2000元需行政部统一采购
- **报销要求**：需提供正规发票和购物清单

### 4. 通讯费报销
| 职级 | 月度通讯补贴 |
|------|------------|
| 高管 | 500元 |
| 总监/高级经理 | 300元 |
| 经理/主管 | 200元 |
| 普通员工 | 100元 |

**说明**：
- 通讯补贴随工资发放，不单独报销
- 特殊岗位（销售、客服）可申请额外通讯补贴

### 5. 培训费报销
- **公司指派培训**：全额报销（学费、教材费、差旅费）
- **自主申请培训**：需提前审批，报销比例50%-100%
- **证书补贴**：取得相关证书后，报销考试费用

## 报销流程

### 1. 报销申请
1. 登录财务系统（https://finance.company.com）
2. 选择报销类型（差旅/招待/办公/其他）
3. 填写报销单，逐项录入费用明细
4. 上传发票照片或扫描件
5. 粘贴原始发票至报销单据粘贴单

### 2. 审批流程
```
员工提交 → 直属领导审批 → 部门负责人审批 → 财务审核 → 出纳付款
    ↓
（超标情况）→ VP审批 → 财务审核 → 出纳付款
```

### 3. 报销时效
- **差旅费**：出差结束后5个工作日内提交
- **其他费用**：费用发生后30天内提交
- **逾期处理**：超过30天需写情况说明，部门负责人审批
- **跨年发票**：原则上不予报销（特殊情况需CFO审批）

### 4. 付款时间
- 每周二、周五统一付款
- 审批通过后3-5个工作日到账

## 发票要求

### 1. 发票类型
- **增值税专用发票**：优先使用，可抵扣进项税
- **增值税普通发票**：可使用
- **电子发票**：与纸质发票同等效力

### 2. 发票规范
- 发票抬头：公司全称（与营业执照一致）
- 税号：必须填写公司统一社会信用代码
- 发票内容：与实际消费一致，不得变更品名
- 发票章：必须加盖发票专用章

### 3. 特殊情况
- **发票遗失**：
  - 提供消费证明（订单截图、付款记录）
  - 填写《发票遗失说明》
  - 部门负责人和财务双重审批
- **无法取得发票**：
  - 提供付款凭证和消费明细
  - 填写《无票报销申请》
  - 需VP级领导审批

## 常见问题FAQ

### Q1: 出差预订机票可以用携程吗？
**A**: 可以。建议使用公司签约的差旅平台（携程商旅、滴滴企业版），可直接开具公司抬头的发票，简化报销流程。

### Q2: 住宿超标怎么办？
**A**: 提前在OA系统提交《超标住宿申请》，说明原因（如展会期间酒店涨价、安全考虑等），经部门负责人和财务审批后可按实际金额报销。

### Q3: 招待客户可以买礼品吗？
**A**: 可以。礼品费用计入业务招待费，单次不超过1000元，需提供购买清单和发票。特殊礼品（如高档烟酒、奢侈品）需VP审批。

### Q4: 报销单被退回了怎么办？
**A**: 查看退回原因（通常备注在报销单上），修正后重新提交。常见问题包括：发票不清晰、金额计算错误、缺少审批附件等。

### Q5: 可以帮同事代报销吗？
**A**: 原则上不允许。特殊情况（如同事出差期间）需本人书面授权，并在报销单中注明"代XXX报销"。

### Q6: 报销款多久到账？
**A**: 审批通过后3-5个工作日到账。每周二、周五统一付款，节假日顺延。

### Q7: 打车发票丢了怎么办？
**A**: 在滴滴/高德等平台下载电子行程单和发票，或提供支付宝/微信付款截图，填写《发票遗失说明》后报销。

### Q8: 可以预支差旅费吗？
**A**: 可以。出差预算超过5000元可申请预支，填写《借款申请单》，经部门负责人和财务审批后发放。出差回来后15天内完成报销冲账。
