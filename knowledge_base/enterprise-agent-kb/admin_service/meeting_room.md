## 预约规则

### 1. 预约权限
| 会议室类型 | 预约权限 | 审批要求 |
|-----------|---------|---------|
| 小会议室（6人以下） | 全体员工 | 无需审批 |
| 中会议室（7-15人） | 全体员工 | 部门负责人审批（外部人员参会） |
| 大会议室（16人以上） | 经理及以上 | 部门负责人审批 |
| VIP厅 | 总监及以上 | 行政总监审批 |
| 培训厅 | HR/培训部 | 行政经理审批 |

### 2. 预约时间
- **提前预约**：至少提前1个工作日
- **最长预约**：可提前14天预约
- **最短时长**：0.5小时
- **最长时长**：4小时（超过需续订或审批）
- **预约时间范围**：8:00-21:00

### 3. 预约流程

#### 线上预约
1. 登录OA系统 → 会议室预约
2. 选择日期、时间、会议室
3. 填写会议主题、参会人数、是否需要设备
4. 提交预约（如需审批，等待审批通过）
5. 收到预约成功通知

#### 取消预约
- **提前2小时取消**：OA系统直接取消
- **2小时内取消**：需电话通知行政部（分机8001）
- **未取消且未使用**：记为"爽约"，累计3次限制预约权限1个月

### 4. 优先规则
- **优先级1**：公司级重要会议（CEO办公室预约）
- **优先级2**：客户接待、外部会议
- **优先级3**：跨部门会议
- **优先级4**：部门内部会议
- **优先级5**：个人工作

冲突时由行政部协调，优先级高的优先使用。

## 使用规范

### 1. 会前准备
- 提前5分钟到达会议室
- 检查设备是否正常（如有问题立即联系IT热线8888）
- 调整座椅、白板、投影仪等设备

### 2. 会中规范
- 保持会议室整洁
- 禁止在会议室进食（茶歇除外）
- 爱护设备，正确使用
- 控制音量，不影响周边会议室

### 3. 会后整理
- 恢复座椅摆放
- 关闭投影仪、电视屏、空调、灯光
- 带走个人物品和垃圾
- 白板内容擦拭干净（如需保留请拍照）

### 4. 设备使用
- **投影仪**：使用完毕后正常关机，不要直接拔电源
- **视频会议系统**：会议结束后挂断并关机
- **白板**：使用水性笔，勿用油性笔
- **电源插座**：合理使用，不要超负荷

## 常见问题FAQ

### Q1: 会议室被占用了怎么办？
**A**: 
- 查看预约系统，确认是否有预约记录
- 如对方未预约，礼貌提醒并出示自己的预约记录
- 如对方有预约（自己忘记），联系行政协调其他会议室
- 紧急情况联系行政部（分机8001）

### Q2: 可以临时预约会议室吗？
**A**: 
- 可以，但需先查询是否有空闲
- 临时预约不保证能预约到理想的时间和会议室
- 建议至少提前1天预约，确保资源可用

### Q3: 会议室设备故障怎么办？
**A**: 
- 拨打IT热线 8888 报修
- 联系行政部（分机8001）协调备用会议室
- IT工程师会在15分钟内到场处理

### Q4: 可以预订下周的会议室吗？
**A**: 
- 可以，最多可提前14天预约
- 建议在周一上午预约全周需要的会议室
- 定期会议可以申请周期性预约（联系行政部）

### Q5: 会议室可以带外部人员进入吗？
**A**: 
- 可以，但需要在前台登记
- 接待人员需提前告知前台访客信息
- VIP厅接待客户需提前通知行政部准备茶歇

### Q6: 可以延长会议时间吗？
**A**: 
- 查看预约系统，确认后续时段是否有人预约
- 如无人预约，可在OA系统续订
- 如后续有人预约，按时结束或协调更换会议室

### Q7: 会议室空调太冷/太热怎么办？
**A**: 
- 使用会议室内的温控面板调节
- 如无法调节，联系行政部（分机8001）
- 建议会议前10分钟开启空调预冷/预热
