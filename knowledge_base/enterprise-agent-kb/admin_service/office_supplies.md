# 办公用品申领规范

## 申领范围

### 1. 个人办公用品
| 类别 | 物品示例 | 申领限额 | 申领频率 |
|------|---------|---------|---------|
| 书写工具 | 签字笔、铅笔、记号笔、荧光笔 | 按需申领 | 每月不超过1次 |
| 纸品 | A4纸、便签纸、笔记本 | A4纸每次不超过2包 | 每月不超过2次 |
| 文件管理 | 文件夹、文件袋、档案盒 | 按需申领 | 按需 |
| 桌面用品 | 订书机、回形针、胶水、剪刀、胶带 | 首次配发后以旧换新 | 按需 |
| 其他 | 计算器、名片夹、印章垫 | 按需申领 | 按需 |

### 2. 部门公共用品
| 类别 | 物品示例 | 申领要求 |
|------|---------|---------|
| 打印耗材 | 硒鼓、墨盒 | 由部门负责人统一申领 |
| 公共文具 | 白板笔、板擦、公共文件夹 | 按需申领 |
| 清洁用品 | 纸巾、垃圾袋、清洁剂 | 按需申领 |
| 茶水间用品 | 纸杯、茶叶、咖啡 | 行政统一采购 |

### 3. 特殊用品
| 类别 | 物品示例 | 申领要求 |
|------|---------|---------|
| 高价值物品 | 计算器（>200元）、装订机 | 需部门负责人审批 |
| 专业工具 | 绘图工具、测量工具 | 需部门负责人审批 |
| 电子设备 | U盘、鼠标、键盘 | 需IT部门确认 |

## 申领流程

### 1. 个人申领流程
```
员工提交申请 → 部门负责人审批（500元以上）→ 行政部发放 → 签收确认
```

**具体步骤**：
1. 登录OA系统 → 行政服务 → 办公用品申领
2. 选择物品类别和数量
3. 填写申领理由（可选）
4. 提交申请
5. 审批通过后，到行政部领取
6. 签收确认

### 2. 部门集中采购
- **适用场景**：部门公共用品、大批量申领
- **申领流程**：
  1. 部门负责人汇总需求
  2. 提交《部门办公用品采购申请》
  3. 行政部审核（2个工作日）
  4. 采购部统一采购（3-5个工作日）
  5. 到货后通知领取

### 3. 紧急申领
- **适用场景**：突发需求、重要客户接待
- **处理方式**：
  - 电话联系行政部（分机8002）
  - 说明紧急原因和所需物品
  - 行政部优先处理，事后补填申请

## 领用时间

### 固定领用时间
| 时间段 | 说明 |
|--------|------|
| 周一至周五 9:00-11:30 | 上午领用时间 |
| 周一至周五 14:00-17:00 | 下午领用时间 |

### 特殊情况
- **紧急领用**：电话联系行政部，可安排非固定时间领取
- **批量领取**：超过20件物品需提前1天预约
- **代领**：需持有申领人书面授权或企业微信确认

## 费用与预算

### 1. 个人额度
- **月度额度**：普通员工100元/月，经理及以上200元/月
- **超额处理**：超额部分需写说明，部门负责人审批

### 2. 部门预算
- 各部门年度办公用品预算由行政部统一编制
- 预算使用率纳入部门考核
- 剩余预算不结转至下一年度

### 3. 费用分摊
- 个人办公用品：计入部门成本
- 公共办公用品：计入行政费用
- 项目专用物品：计入项目成本

## 库存查询

### 在线查询
- 登录OA系统 → 行政服务 → 办公用品库存
- 可查询物品名称、规格、库存数量、预计到货时间

### 常见库存更新频率
- **高频物品**（A4纸、签字笔）：每周补充
- **中频物品**（文件夹、笔记本）：每两周补充
- **低频物品**（特殊文具）：按月补充

## 常见问题FAQ

### Q1: 想要的物品库存没有了怎么办？
**A**: 
- 在OA系统提交《物品采购申请》
- 行政部会在3-5个工作日内采购
- 紧急情况联系行政部（分机8002）

### Q2: 可以申领私人用品吗？
**A**: 
- 不可以，办公用品仅限工作使用
- 私自占用视为违规行为，需照价赔偿

### Q3: 申领的办公用品坏了可以换吗？
**A**: 
- 可以，以旧换新
- 携带损坏物品到行政部更换
- 非人为损坏免费更换，人为损坏需自费

### Q4: 可以一次申领大量A4纸吗？
**A**: 
- 个人单次不超过2包（500张/包）
- 部门需求由部门负责人统一申领
- 超过10包需行政经理审批

### Q5: 离职时办公用品要归还吗？
**A**: 
- 消耗品（笔、纸等）无需归还
- 耐用品（订书机、计算器等）需归还
- 未归还需照价赔偿
