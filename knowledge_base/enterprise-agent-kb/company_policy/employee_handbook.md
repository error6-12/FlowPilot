# 员工手册

## 第一章 公司简介

### 1.1 公司愿景
成为行业领先的创新型企业，为社会创造价值，为员工提供发展平台。

### 1.2 核心价值观
- **客户第一**：始终以客户需求为导向
- **诚信正直**：言行一致，坚守底线
- **协作共赢**：团队合作，共同成长
- **追求卓越**：精益求精，持续创新
- **尊重包容**：多元共融，平等对待

### 1.3 组织架构
- **董事会**：公司最高决策机构
- **CEO办公室**：负责公司日常经营管理
- **技术中心**：负责产品研发、技术创新
- **市场部**：负责市场推广、品牌建设
- **销售部**：负责客户开拓、业绩达成
- **人力资源部**：负责招聘、培训、薪酬绩效
- **财务部**：负责财务管理、资金运作
- **行政部**：负责行政后勤、办公管理

## 第二章 入职管理

### 2.1 入职流程
1. **Offer确认**：接受录用通知书，确认薪资福利
2. **入职体检**：到指定医院完成入职体检
3. **报到材料**：
   - 身份证原件及复印件
   - 学历学位证书原件及复印件
   - 离职证明（应届生除外）
   - 银行卡复印件（工资卡）
   - 1寸/2寸照片各4张
   - 相关资格证书（如有）
4. **入职办理**：
   - 签订劳动合同
   - 填写员工信息表
   - 领取办公用品
   - IT系统账号开通
   - 入职培训

### 2.2 试用期
- **试用期时长**：合同期3年，试用期6个月
- **试用期工资**：转正工资的80%
- **试用期考核**：
  - 第1个月：入职适应评估
  - 第3个月：中期考核
  - 第6个月：转正考核
- **转正流程**：
  1. 员工提交转正申请
  2. 直属领导评估
  3. 部门负责人审批
  4. HR审核并发放转正通知

### 2.3 实习生管理
- **实习时长**：不少于3个月
- **实习补贴**：150-200元/天（根据岗位）
- **转正机会**：表现优秀可获得return offer

## 第三章 考勤制度

### 3.1 工作时间
- **标准工时**：周一至周五 9:00-18:00
- **午休时间**：12:00-13:30（1.5小时）
- **弹性工作**：
  - 上班时间弹性：8:30-10:00
  - 工作满8小时即可
  - 核心工作时间：10:00-16:00（必须在岗）

### 3.2 打卡规则
- **打卡方式**：企业微信打卡、人脸识别、指纹打卡
- **打卡地点**：公司办公区域范围内
- **外勤打卡**：需拍照并填写外勤事由
- **忘记打卡**：每月允许3次补卡，需主管审批

### 3.3 迟到早退
| 情况 | 处理方式 |
|------|---------|
| 迟到≤15分钟 | 不扣款，每月超过3次按半天事假处理 |
| 迟到15-30分钟 | 扣款50元/次 |
| 迟到30-60分钟 | 扣款100元/次，记警告一次 |
| 迟到>60分钟 | 按旷工半天处理 |
| 早退≤30分钟 | 扣款50元/次 |
| 早退>30分钟 | 按旷工半天处理 |

### 3.4 加班管理
- **加班申请**：需提前在OA系统申请
- **加班认定**：工作日20:00后、周末全天、法定节假日
- **加班补偿**：
  - 工作日加班：可调休或1.5倍工资
  - 周末加班：可调休或2倍工资
  - 法定节假日：3倍工资（不可调休）
- **加班餐补**：加班至21:00后，补贴30元/餐
- **加班交通**：加班至22:00后，打车费全额报销

### 3.5 旷工处理
- **旷工定义**：未请假或请假未批准而缺勤
- **处理方式**：
  - 旷工1天：扣3倍日工资，书面警告
  - 旷工2天：扣6倍日工资，严重警告
  - 连续旷工3天或年度累计旷工5天：解除劳动合同

## 第四章 薪酬福利

### 4.1 薪酬结构
- **基本工资**：岗位固定工资
- **绩效工资**：根据月度/季度考核发放
- **年终奖金**：根据公司业绩和个人表现，1-6个月工资
- **项目奖金**：项目完成后按贡献分配
- **其他补贴**：交通补贴、通讯补贴、餐饮补贴

### 4.2 发薪时间
- **发薪日**：每月10日发放上月工资
- **遇节假日**：提前至最近工作日发放
- **工资条**：通过OA系统查看电子工资条

### 4.3 社会保险
- **五险一金**：养老、医疗、失业、工伤、生育保险 + 住房公积金
- **缴纳基数**：按实际工资缴纳（上限为当地社平工资3倍）
- **公积金比例**：公司12%，个人12%

### 4.4 补充福利
- **商业保险**：补充医疗保险、意外险、重疾险
- **年度体检**：每年一次全面体检
- **节日礼品**：春节、端午、中秋等节日礼品/礼金
- **生日福利**：生日当天放假半天 + 生日礼品
- **团建活动**：部门季度团建，公司年度旅游
- **员工关怀**：婚育礼金、丧事慰问金

### 4.5 股权激励
- **适用对象**：核心员工、高管
- **授予条件**：入职满1年，绩效B+及以上
- ** vesting**：4年归属，每年25%
- **行权价格**：按授予时估值折扣

## 第五章 行为规范

### 5.1 职业操守
- 遵守法律法规和公司制度
- 保守公司商业秘密
- 不利用职务之便谋取私利
- 不接受利益相关方的礼品/宴请（价值超过200元需上报）

### 5.2 着装要求
- **商务场合**：正装或商务休闲
- **日常办公**：整洁得体，不穿拖鞋、短裤
- **特殊岗位**：按要求穿着工装/防护装备

### 5.3 办公环境
- 保持工位整洁
- 不在办公区域大声喧哗
- 不在工位进食异味食物
- 爱护公共设施

### 5.4 信息安全
- 不在公共场合讨论公司机密
- 不私自拷贝公司数据
- 不使用个人邮箱处理工作邮件
- 离开工位锁屏

## 第六章 离职管理

### 6.1 辞职流程
1. **提前通知**：
   - 试用期：提前3天
   - 正式员工：提前30天
2. **提交申请**：OA系统提交离职申请
3. **面谈**：HR进行离职面谈
4. **工作交接**：填写交接清单，完成工作移交
5. **物品归还**：归还电脑、门禁卡、办公用品等
6. **离职手续**：
   - 财务结算（工资、报销、借款）
   - IT账号注销
   - 行政物品清退
   - 开具离职证明

### 6.2 离职时间
- **最后工作日**：申请批准后30天
- **社保公积金**：当月15日前离职不缴当月，15日后离职缴纳当月
- **工资结算**：最后工作日一次性结清

### 6.3 竞业限制
- **适用对象**：高管、核心技术、核心销售
- **竞业期限**：离职后6-12个月
- **补偿标准**：月工资的30%-50%
- **违约金**：补偿金的3-5倍

## 常见问题FAQ

### Q1: 入职后多久可以转正？
**A**: 标准试用期6个月，表现优秀可申请提前转正（最少3个月）。

### Q2: 弹性工作怎么申请？
**A**: 入职即可享受弹性工作，只要在8:30-10:00之间到岗，工作满8小时即可。核心时间10:00-16:00必须在岗。

### Q3: 年终奖什么时候发？
**A**: 一般在春节前发放，具体金额根据公司年度业绩和个人绩效考核结果确定。

### Q4: 公司有哪些带薪假期？
**A**: 年假（5-20天）、病假、婚假（3-10天）、产假（98天+）、陪产假（15天）、丧假（1-3天）。详见请假制度。

### Q5: 如何申请内部转岗？
**A**: 在当前岗位工作满1年，绩效B+及以上，可申请内部转岗。需现任领导同意，接收部门面试通过。

### Q6: 公司有什么培训资源？
**A**: 新人入职培训、专业技能培训、管理能力培训、外部培训报销、在线学习平台等。
