# 项目立项管理流程

## 一、立项条件

### 1.1 可申请立项的情形
- 新产品/新业务线开发需求
- 公司内部效率提升项目（如系统升级、流程优化）
- 客户定制化项目（已签约或有明确意向）
- 技术预研/创新探索类项目
- 合规/安全整改类项目

### 1.2 立项发起资格
| 发起人角色 | 可发起的项目类型 | 审批层级 |
|-----------|----------------|---------|
| 普通员工 | 效率提升类、技术创新类 | 部门经理 |
| 项目经理/主管 | 所有类型 | 部门经理 |
| 部门经理/总监 | 所有类型 | VP |
| VP及以上 | 所有类型 | CEO |

### 1.3 立项前置条件
- 已完成需求调研和可行性分析
- 有明确的项目目标和预期收益
- 已初步评估所需资源（人力、预算、时间）
- 非重复立项（OA系统查重）

## 二、立项申请流程

### 2.1 提交立项申请
1. 登录OA系统 → 项目管理 → 新建项目立项
2. 填写立项申请表：
   - **项目名称**
   - **项目背景与目标**（必填）
   - **可行性分析摘要**（必填）
   - **预期收益**（量化指标，必填）
   - **项目周期**（预计起止时间，必填）
   - **所需资源**（人力/预算/设备，必填）
   - **风险评估**（必填）
   - **附件**：可行性报告、需求文档、预算明细等

### 2.2 审批流程
```
发起人提交 → 部门经理审核 → PMO评审 → 财务预算审核 → VP/CEO审批 → 立项完成
```

| 项目预算 | 审批链路 |
|---------|---------|
| ≤10万 | 部门经理 → PMO → 完成 |
| 10-50万 | 部门经理 → PMO → 财务 → VP |
| 50-200万 | 部门经理 → PMO → 财务 → VP → CEO |
| >200万 | 部门经理 → PMO → 财务 → VP → CEO → 董事会 |

### 2.3 审批时效
| 审批环节 | 时限 | 超时处理 |
|---------|------|---------|
| 部门经理审核 | 2个工作日 | 自动催办 |
| PMO评审 | 3个工作日 | 自动催办，5个工作日升级至PMO负责人 |
| 财务审核 | 2个工作日 | 自动催办 |
| VP/CEO审批 | 3个工作日 | 自动催办，5个工作日自动转审 |

### 2.4 各审批环节评审要点
| 环节 | 评审内容 |
|------|---------|
| 部门经理 | 项目必要性、与部门战略匹配度、初步资源可行性 |
| PMO | 项目可行性、资源冲突检查、与在建项目优先级对比 |
| 财务 | 预算合理性、ROI分析、资金来源确认 |
| VP/CEO | 战略价值、公司级资源分配 |

## 三、驳回后重新发起

### 3.1 驳回原因类型
| 驳回原因 | 说明 | 重新发起建议 |
|---------|------|------------|
| 可行性不足 | 方案论证不充分 | 补充可行性分析，完善方案 |
| ROI不达标 | 预期收益不达投资标准 | 重新核算收益或调整项目规模 |
| 资源冲突 | 与现有项目资源冲突 | 调整项目时间或资源需求 |
| 预算超标 | 预算超出部门/公司承受范围 | 削减预算或分期实施 |
| 重复立项 | 与已有项目高度重合 | 合并到已有项目或明确差异化 |
| 信息不完整 | 申请材料缺失 | 补齐材料后重新提交 |

### 3.2 重新发起规则
- 被驳回后可随时重新提交，无等待期限制
- 重新提交时需针对驳回原因修改立项申请
- 在申请表中标注"重新提交"并附上一次驳回编号
- 审批流程从头开始，但审批人可参考上次的评审意见
- 同一项目连续被驳回3次，需与PMO面对面沟通后再提交

## 四、立项与其他流程的关联

### 4.1 立项通过后自动触发
- 项目预算额度冻结
- PMO分配项目编号
- 项目经理可在系统中组建团队
- 关联的采购需求自动流转至采购流程

### 4.2 立项阶段并行发起采购
- 立项申请中可勾选"需专项采购"
- 勾选后采购申请自动关联立项编号
- 立项审批通过后，采购流程自动进入审批（无需重复提交项目背景）
- 立项被驳回，关联的采购申请自动取消

### 4.3 立项阶段并行发起招聘
- 立项申请中可勾选"需新增招聘"
- 审批通过后自动流转至HR招聘流程

## 五、常见问题FAQ

### Q1: 个人想法还没成熟，可以先提交立项吗？
**A**: 可以提交"预立项申请"，仅需填写项目概念和初步可行性，由PMO评估是否值得正式立项。预立项不需要完整材料。

### Q2: 立项审批期间可以修改申请内容吗？
**A**: 在"待审批"状态不可修改。如需修改，先撤回申请，修改后重新提交。

### Q3: 项目立项后需要定期汇报吗？
**A**: 需要。PMO要求所有立项项目每月提交进度报告，重大项目每两周汇报一次。

### Q4: 项目取消或终止怎么处理？
**A**: 在OA提交"项目终止申请"，说明终止原因，经原审批链路审批。已冻结预算释放，已采购物资由行政部处理。
