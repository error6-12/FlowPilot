# 审批流程规范

## 一、审批流程总览

所有企业流程都需经过审批。审批遵循以下通用规则：

- **逐级审批**：按职级逐级上报，不可跳级
- **并行会签**：涉及多部门的流程需相关部门负责人并行审批
- **超时自动提醒**：审批人超过24小时未处理，系统自动催办
- **自动转审**：审批人请假/出差超过3天，自动转给指定代审人
- **全程留痕**：每一步操作都记录审计日志

## 二、请假审批流程

### 2.1 审批规则
| 请假天数 | 审批人 | 抄送 |
|---------|--------|------|
| ≤1天 | 直属主管 | — |
| 1-3天 | 直属主管 → 部门经理 | HR |
| 3-7天 | 直属主管 → 部门经理 → HR | — |
| >7天 | 直属主管 → 部门经理 → HR → VP | — |

### 2.2 审批动作
- **批准**：审批通过，流程进入下一环节或生效
- **驳回**：需填写驳回理由，流程退回发起人
- **转审**：转给其他审批人处理
- **要求补充**：要求申请人补充材料（如医院证明等）

### 2.3 特殊规则
- 年假需提前3天申请（紧急年假除外）
- 病假超过3天需提供医院证明
- 婚假/产假/丧假需附相关证明材料
- 法定节假日前后1天请假需VP审批

## 三、报销审批流程

### 3.1 审批规则
| 报销金额 | 审批人 | 附加条件 |
|---------|--------|---------|
| ≤1,000元 | 直属主管 | — |
| 1,000-10,000元 | 直属主管 → 部门经理 | — |
| 10,000-50,000元 | 直属主管 → 部门经理 → 财务 | 财务核实发票 |
| >50,000元 | 直属主管 → 部门经理 → 财务 → VP | VP终审 |

### 3.2 审批动作
- **批准**：进入财务打款队列
- **驳回**：退回申请人，需修改后重新提交
- **要求补充材料**：常见情况：
  - 发票不清晰，需重新上传
  - 缺少消费明细/水单
  - 金额与发票不符
  - 缺少事前审批单
- **转审**：转给其他审批人

### 3.3 财务审核要点
- 发票真伪验证
- 报销标准是否超标
- 预算余额是否充足
- 重复报销检查

## 四、IT工单审批流程

### 4.1 审批规则
| 工单类型 | 处理人 | 升级条件 |
|---------|--------|---------|
| P0-系统故障 | IT全员响应 | IT总监直接介入 |
| P1-紧急 | IT高级工程师 | 30分钟未响应→IT主管 |
| P2-高 | IT工程师 | 4小时未解决→IT主管 |
| P3-中 | IT工程师/值班人员 | 24小时未解决→IT主管 |

### 4.2 处理动作
- **接单**：确认工单并开始处理
- **转派**：转给更合适的处理人
- **挂起**：等待配件/第三方支持，暂停计时
- **解决**：标记问题已解决，等待用户确认
- **关闭**：用户确认解决或超48小时自动关闭

### 4.3 采购审批（需更换硬件时）
| 金额 | 审批人 |
|------|--------|
| ≤500元 | IT主管 |
| 500-5,000元 | IT经理 |
| >5,000元 | IT总监 + 财务 |

## 五、资源预订审批流程

### 5.1 会议室预订
| 条件 | 审批要求 |
|------|---------|
| 普通会议室，≤2小时 | 无需审批，直接预订 |
| 普通会议室，>2小时 | 行政前台确认 |
| 大型会议室（10F/12F） | 行政经理审批 |
| VIP接待室 | 行政总监审批 |
| 全公司大会场地 | VP审批 |

### 5.2 其他资源预订
| 资源类型 | 审批人 |
|---------|--------|
| 公司车辆 | 行政主管 |
| 投影仪/特殊设备 | 行政前台 |
| 访客停车位 | 行政前台 |
| 长期固定工位 | 行政经理 + 部门经理 |

## 六、审批操作规范

### 6.1 审批时效要求
| 类型 | 审批时限 | 超时处理 |
|------|---------|---------|
| 请假 | 24小时内 | 自动催办，48小时自动转审 |
| 报销 | 48小时内 | 自动催办，72小时自动转审 |
| IT工单 | 按SLA（见IT工单流程） | 按SLA升级 |
| 资源预订 | 4小时内 | 自动转给行政前台 |

### 6.2 驳回规范
驳回时**必须**填写理由，常见驳回原因：
- 信息不完整（需补充材料）
- 不符合政策规定（需说明具体条款）
- 预算不足（建议调整金额或时间）
- 时间冲突（建议替代方案）

### 6.3 审批委托
- 审批人休假/出差可设置委托审批人
- 委托需在OA中提前设置
- 未设置委托且超过时限，自动转给上级

## 七、审计记录

### 7.1 审计日志格式
每条审批操作都会记录以下信息：

```
{
  "flow_id": "请假-20240301-001",     // 流程编号
  "flow_type": "请假",                 // 流程类型
  "operator": "张三（工号:10086）",     // 操作人
  "action": "批准",                    // 操作类型：提交/批准/驳回/转审/补充/撤回
  "timestamp": "2024-03-01T10:30:00+08:00",  // 操作时间
  "comment": "同意，注意交接工作",       // 审批意见
  "from_status": "待审批",             // 操作前状态
  "to_status": "已批准",              // 操作后状态
  "ip": "10.0.1.100",                // 操作IP
  "device": "企业微信-移动端"           // 操作设备
}
```

### 7.2 审计查询
- **员工**：可查询自己的流程审计记录
- **审批人**：可查询自己审批的所有记录
- **HR/行政**：可查询所有流程记录
- **运营人员**：可通过后台查询全量审计日志

## 常见问题FAQ

### Q1: 审批人一直不处理怎么办？
**A**: 系统会在超时后自动催办。如仍未处理，可在流程详情中点击"催办"按钮，或联系审批人的上级。

### Q2: 我的请假被驳回了，可以重新提交吗？
**A**: 可以。根据驳回理由修改或补充信息后重新提交，审批时效从重新提交时重新计算。

### Q3: 可以同时提交多个请假申请吗？
**A**: 可以，但同一天不能有两种请假类型重叠。

### Q4: 报销审批通过后多久到账？
**A**: 审批通过后，财务在每月15日和30日统一打款。如遇节假日顺延。

### Q5: 撤回申请有什么限制？
**A**: 流程在"待审批"状态可撤回；一旦有人已审批，则不能撤回，需联系审批人驳回。
