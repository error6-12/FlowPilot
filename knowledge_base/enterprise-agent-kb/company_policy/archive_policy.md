# 流程归档与保存制度

## 一、归档范围

所有通过OA系统发起和处理的流程，包括但不限于：
- 请假/出差/加班流程
- 费用报销/采购流程
- IT工单
- 资源预订
- 项目立项/变更/终止
- 调岗/离职流程
- 审批记录

## 二、保存期限

### 2.1 各类流程保存期限
| 流程类型 | 保存期限 | 保存方式 |
|---------|---------|---------|
| 请假流程 | 员工离职后3年 | 电子归档 |
| 费用报销 | 10年（财务档案要求） | 电子+纸质 |
| 采购流程 | 10年（含合同附件） | 电子+纸质 |
| IT工单 | 3年 | 电子归档 |
| 项目立项 | 项目结束后5年 | 电子归档 |
| 调岗流程 | 员工离职后3年 | 电子归档 |
| 离职流程 | 员工离职后10年 | 电子+纸质 |
| 审批日志 | 流程结束后5年 | 电子归档 |
| 系统操作日志 | 1年 | 电子归档 |

### 2.2 保存期限计算
- 从流程"已完成"或"已关闭"状态的时间点开始计算
- 涉及财务的从会计年度结束后开始计算
- 涉及员工的从员工离职日期后开始计算

## 三、归档流程

### 3.1 自动归档
- 流程结束（已完成/已关闭/已取消）后30天自动归档
- 归档后流程状态变为"已归档"，不可修改
- 归档后仍可按权限查阅

### 3.2 手动归档
- 未完成但已无意义的流程（如长期挂起），可由管理员手动归档
- 手动归档需记录归档原因

## 四、调阅方式

### 4.1 在线调阅
| 角色 | 可查阅范围 | 调阅方式 |
|------|----------|---------|
| 流程发起人 | 自己发起的所有流程 | OA → 我的流程 → 已归档 |
| 审批人 | 自己参与审批的流程 | OA → 审批中心 → 已归档 |
| 部门经理 | 本部门已归档流程 | OA → 部门管理 → 已归档流程 |
| HR | HR相关已归档流程 | OA → HR管理 → 归档查询 |
| 财务 | 财务相关已归档流程 | OA → 财务管理 → 归档查询 |
| Agent运营 | 所有流程的日志（脱敏） | 管理后台 → 归档日志 |

### 4.2 纸质档案调阅
- 适用于报销单据、合同原件等纸质档案
- 在OA提交"档案调阅申请"
- 档案管理员审批后安排现场查阅
- 纸质档案原则上不外借，如需借出需VP审批

### 4.3 导出与下载
| 操作 | 权限要求 |
|------|---------|
| 在线查看 | 有该流程的查看权限即可 |
| 导出PDF | 需部门负责人审批 |
| 批量导出 | 需VP审批 |
| 导出含敏感信息 | 需数据Owner + 合规部门审批 |

## 五、过期销毁

### 5.1 销毁流程
```
系统自动标记过期 → 档案管理员审核 → 生成销毁清单 → 合规部门确认 → VP审批 → 执行销毁 → 销毁记录归档
```

### 5.2 销毁规则
- 电子档案：永久删除，不可恢复
- 纸质档案：碎纸机销毁
- 销毁记录永久保存（含销毁时间、内容、执行人）

### 5.3 特殊保留
- 涉及诉讼/审计的流程，保存期限延长至诉讼/审计结束后3年
- 员工提出劳动争议的，相关流程保存至争议解决后

## 六、常见问题FAQ

### Q1: 我怎么找到很久以前提交的流程？
**A**: 在OA → 我的流程 → 筛选"已归档"状态，可按时间范围搜索。超过在线查看期限的，需联系档案管理员。

### Q2: 已归档的流程发现有错误，可以修改吗？
**A**: 已归档流程不可直接修改。如需更正，需提交"归档流程更正申请"，经原审批人确认后进行更正并记录更正日志。

### Q3: 前同事发起的流程我能看到吗？
**A**: 如果你是该流程的审批人或有查看权限，可以查看。普通同事无法查看他人流程。

### Q4: 报销单据的纸质发票保存多久？
**A**: 按照财务档案管理要求，报销相关纸质单据保存10年。到期后按销毁流程处理。
