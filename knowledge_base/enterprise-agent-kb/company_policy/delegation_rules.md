# 代理发起与代办规则

## 一、基本原则

- 涉及个人身份确认的流程，原则上须本人发起
- 涉及通用业务申请的流程，可委托他人代办
- 代办人须持有申请人的书面授权或在OA中设置代办授权

## 二、可代理发起的流程

### 2.1 可代办流程清单
| 流程类型 | 是否可代办 | 代办条件 |
|---------|-----------|---------|
| 请假申请 | ✅ 可代办 | 紧急情况（如员工突发疾病），直属上级或HR可代办 |
| 费用报销 | ✅ 可代办 | 员工出差期间，经书面授权可代办 |
| IT工单 | ✅ 可代办 | 任何人可代他人提交IT工单 |
| 会议室预订 | ✅ 可代办 | 行政秘书、助理可代办 |
| 办公用品申领 | ✅ 可代办 | 部门助理可统一代办 |
| 采购申请 | ✅ 可代办 | 部门内可互相代办，需注明代办人 |
| 出差申请 | ✅ 可代办 | 紧急情况由直属上级代办 |

### 2.2 必须本人发起的流程
| 流程类型 | 原因 |
|---------|------|
| 转正申请 | 涉及个人绩效自评 |
| 离职申请 | 涉及个人意愿确认 |
| 薪资调整申请 | 涉及个人薪酬隐私 |
| 晋升申请 | 涉及个人述职 |
| 培训服务协议签署 | 涉及个人法律承诺 |
| 竞业限制协议签署 | 涉及个人法律承诺 |
| 合规举报 | 涉及举报人保护 |
| 绩效考核自评 | 涉及个人评价 |

## 三、代办授权方式

### 3.1 临时授权（单次有效）
- 申请人在OA中填写"临时代办授权"
- 指定代办人和代办事项
- 代办人提交时须上传授权截图
- 流程中注明"由XXX代办"

### 3.2 长期授权（持续有效）
- 在OA"个人设置" → "代办授权"中设置
- 指定代办人和授权范围
- 有效期最长6个月，到期需重新授权
- 可随时取消授权

### 3.3 系统默认代办
| 情形 | 默认代办人 |
|------|----------|
| 员工病假无法操作 | 直属上级 |
| 员工出差无法操作 | 直属上级或部门助理 |
| 新员工尚未开通账号 | HR代办入职相关流程 |

## 四、代办操作规范

### 4.1 代办提交要求
- 流程中自动标注"由XXX代办"
- 代办人须在备注中说明代办原因
- 紧急代办需在24小时内补办书面授权

### 4.2 代办权限限制
- 代办人只能使用申请人的身份信息提交
- 代办人不能替申请人进行审批操作
- 代办流程的后续审批不受影响

### 4.3 责任界定
- 经授权的代办：申请人承担流程内容的真实性和准确性
- 未经授权的代办：代办人承担全部责任
- 代办信息有误：由申请人负责更正

## 五、审批环节的代理

### 5.1 审批委托（与代办不同）
审批环节的代理参见 `approval_process.md` 中的"审批委托"章节：
- 审批人可设置委托审批人
- 委托审批人以自己名义进行审批
- 审批记录中注明"受XXX委托审批"

## 六、常见问题FAQ

### Q1: 同事生病了，我能帮他提交请假吗？
**A**: 可以。紧急情况（如突发疾病）直属上级或HR可以直接代办，无需书面授权，但需在24小时内补办。

### Q2: 我出差在外地，同事能帮我提交报销吗？
**A**: 可以，但需要你提前在OA设置代办授权，或给同事书面授权（企业微信/邮件均可）。

### Q3: 代办提交的流程，审批人能看到是代办的吗？
**A**: 能。流程中会自动标注代办人信息和代办原因。

### Q4: 离职申请可以找人代办吗？
**A**: 不可以。离职申请涉及个人意愿确认，必须本人发起。如果员工无法操作，可由HR线下协助后在系统中补录。
