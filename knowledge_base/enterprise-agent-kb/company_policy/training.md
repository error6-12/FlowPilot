# 培训发展制度

## 培训体系

### 1. 新员工入职培训

#### 1.1 公司级培训（第1-2天）
| 时间 | 内容 | 讲师 | 地点 |
|------|------|------|------|
| 9:00-10:00 | 公司文化与发展历程 | CEO/HRD | 培训室A |
| 10:00-11:00 | 组织架构与业务介绍 | 各事业部负责人 | 培训室A |
| 11:00-12:00 | 行政制度与办公环境 | 行政部 | 培训室A |
| 14:00-15:30 | IT系统与工具使用 | IT部 | 培训室A |
| 15:30-17:00 | 财务报销与HR系统 | 财务部/HR | 培训室A |

#### 1.2 部门级培训（第3-5天）
- 部门业务介绍
- 岗位职责说明
- 工作流程与工具
- 团队成员认识
- 导师1对1沟通

#### 1.3 岗位技能培训（第2-4周）
- 岗位所需专业技能
- 内部系统操作
- 实战项目演练
- 阶段考核

### 3. 外部培训

#### 3.1 公司资助的外部培训
| 培训类型 | 资助比例 | 审批层级 |
|---------|---------|---------|
| 行业认证考试 | 100%（通过后） | 部门经理 |
| 行业会议/峰会 | 100% | 部门经理 |
| 付费线上课程 | 70% | 直属主管 |
| 学历教育（MBA等） | 50%（上限10万） | VP+HR |
| 外部培训班 | 视情况 | 部门经理 |

#### 3.2 申请条件
- 培训内容须与当前岗位或发展方向相关
- 完成培训后需提交学习总结
- 通过考试认证的费用全额报销
- 学历教育需签订培训服务协议（服务期2年）

## 培训学分制度

### 1. 学分要求
| 职级 | 年度最低学分 | 必修学分 | 选修学分 |
|------|------------|---------|---------|
| T1-T2/P1-P2 | 24学分 | 12学分 | 12学分 |
| T3-T4/P3-P4 | 32学分 | 16学分 | 16学分 |
| T5+/P5+/M1+ | 40学分 | 20学分 | 20学分 |

### 2. 学分获取方式
| 方式 | 学分 |
|------|------|
| 参加内部培训（每小时） | 1学分 |
| 完成线上课程（每小时） | 0.5学分 |
| 担任内部讲师 | 8学分/次 |
| 技术分享/演讲 | 4学分/次 |
| 撰写技术文档/博客 | 2学分/篇 |
| 获得行业认证 | 16学分/证 |
| 参加行业会议 | 4学分/天 |
| 带教新人（完成试用期） | 8学分/人 |

### 3. 学分管理
- 学分按自然年统计，12月31日清零
- 未达标的员工影响年度绩效评定
- 连续2年未达标，晋升申请不予受理

## 导师制度

### 1. 导师职责
- 帮助新人熟悉公司文化和环境
- 制定新人前3个月的学习计划
- 每周至少1次1对1沟通（每次30分钟）
- 定期评估新人成长情况
- 协助新人完成试用期目标

### 2. 导师资格
- 入职满1年
- 绩效B+及以上
- 直属主管推荐
- 完成导师培训（4小时）

### 3. 导师激励
- 导师津贴：500元/月
- 带教成功：一次性奖励2000元
- 带教学分：8学分/人
- 优秀导师评选：年度表彰

## 常见问题FAQ

### Q1: 想学习某项新技术，公司会报销课程费用吗？
**A**: 与工作相关的付费课程，可申请70%报销。需在OA提交"培训申请"，附课程说明和学习计划，直属主管审批。

### Q2: 培训时间是工作时间还是个人时间？
**A**: 公司安排的培训均在工作时间进行。外部培训如因时间冲突需占用周末，可申请调休。

### Q3: 没有完成年度学分会怎样？
**A**: 影响年度绩效评定（最多降1档），且次年晋升申请不予受理。

### Q4: 可以申请参加外部行业会议吗？
**A**: 可以。在OA提交参会申请，说明参会价值和预期收获，部门经理审批。通过后费用全额报销。

### Q5: 如何成为内部讲师？
**A**: 在某个领域有较深积累即可申请。联系HR培训组，提交课程大纲，通过试讲后即可成为认证讲师，享受讲师津贴。

### Q6: 新人没有导师怎么办？
**A**: 入职后如未收到导师分配通知，可主动向直属主管提出。公司要求所有新人都有对应导师。
