# 流程查询与操作指引

## 一、流程状态说明

所有流程都有以下标准状态：

| 状态 | 含义 | 可执行操作 |
|------|------|-----------|
| 草稿 | 已保存但未提交 | 编辑、提交、删除 |
| 待审批 | 已提交，等待审批人处理 | 撤回、催办 |
| 审批中 | 多级审批，部分已审批 | 催办 |
| 待补充材料 | 审批人要求补充信息 | 补充材料、撤回 |
| 已批准 | 审批全部通过 | 查看详情 |
| 已驳回 | 审批被拒绝 | 修改后重新提交、查看详情 |
| 已撤回 | 发起人主动撤回 | 重新编辑提交 |
| 已完成 | 流程全部结束 | 查看详情 |
| 已取消 | 流程被作废 | 查看详情 |

## 二、流程查询

### 2.1 我发起的流程

#### 查询方式
1. **OA系统**：进入"我的流程" → "我发起的"
2. **企业微信**：工作台 → 流程中心 → 我发起的
3. **Agent对话**：直接问"查看我的请假申请"、"我提交的报销到哪了"

#### 可查看信息
- 流程编号、类型、提交时间
- 当前状态和所在审批节点
- 各级审批人及审批意见
- 流程时间线（每一步的操作记录）

### 2.2 待我审批的流程

#### 查询方式
1. **OA系统**：进入"审批中心" → "待处理"
2. **企业微信**：工作台 → 审批中心（显示待办数量红点）
3. **Agent对话**：问"我有哪些待审批的流程"

#### 待办提醒
- 新待办：企业微信即时推送通知
- 超时提醒：超24小时未处理，系统自动催办
- 催办提醒：发起人主动催办时推送

### 2.3 我已处理的流程

#### 查询方式
1. **OA系统**：进入"审批中心" → "已处理"
2. **Agent对话**：问"我最近审批了哪些流程"

## 三、流程操作

### 3.1 发起流程

#### 请假申请
通过Agent发起时需提供的信息：
- **必填**：请假类型（年假/病假/事假/婚假/产假/陪产假/丧假）
- **必填**：开始日期、结束日期
- **必填**：请假原因
- **选填**：工作交接人
- **附件**：病假需附医院证明，婚假需附结婚证等

#### 费用报销
通过Agent发起时需提供的信息：
- **必填**：报销类型（差旅/业务招待/办公用品/通讯/培训）
- **必填**：报销金额
- **必填**：费用发生日期
- **必填**：费用说明
- **必填**：发票照片（清晰完整）
- **选填**：关联的事前审批单号

#### IT工单
通过Agent发起时需提供的信息：
- **必填**：问题描述（尽量详细）
- **必填**：影响范围（仅个人/影响团队/影响部门）
- **必填**：设备编号（资产标签号）
- **选填**：错误截图
- 紧急程度由系统根据描述自动判定，也可手动调整

#### 资源预订
通过Agent发起时需提供的信息：
- **必填**：资源类型（会议室/投影仪/车辆/停车位）
- **必填**：开始时间、结束时间
- **选填**：参会人数、是否需要投屏、茶水服务等

### 3.2 审批操作

#### 批准
- 点击"同意"按钮
- 可填写审批意见（建议填写）
- 流程自动流转到下一审批人

#### 驳回
- 点击"驳回"按钮
- **必须填写驳回理由**
- 流程退回发起人，状态变为"已驳回"

#### 要求补充材料
- 点击"补充材料"按钮
- 说明需要补充什么材料
- 流程状态变为"待补充材料"
- 发起人补充后重新进入审批

#### 转审
- 点击"转审"按钮
- 选择转审对象
- 填写转审理由
- 流程转给新的审批人

#### 批量审批
- 待办列表支持多选
- 同类流程可批量批准（需逐条填写意见）
- 不同类流程不可批量操作

### 3.3 撤回流程

#### 撤回条件
- 流程状态为"待审批"或"审批中"
- 尚无任何审批人已批准
- 一旦有人批准，不可撤回

#### 撤回方式
1. OA系统：进入流程详情 → 点击"撤回"
2. Agent对话：说"撤回我的请假申请"
3. 企业微信：待办中左滑撤回

#### 撤回后
- 流程状态变为"已撤回"
- 可重新编辑后再次提交
- 审批时效从重新提交时重新计算

### 3.4 补充材料

#### 操作方式
1. 收到"待补充材料"通知
2. 查看审批人要求补充的内容
3. 在流程详情中上传补充材料
4. 点击"提交补充"

#### 常见补充场景
- 报销：补充发票照片、消费明细
- 请假：补充医院证明、相关证明
- IT工单：补充错误截图、详细现象描述

### 3.5 催办

#### 催办方式
- OA系统：流程详情 → 点击"催办"
- 企业微信：待办卡片 → 催办
- Agent对话：说"帮我催一下XX的审批"

#### 催办效果
- 审批人收到催办通知
- 超过24小时未处理自动催办
- 超过48小时自动转审给代审人

## 四、流程编号规则

### 编号格式
`{流程类型}-{日期}-{序号}`

| 流程类型 | 前缀 | 示例 |
|---------|------|------|
| 请假 | QL | QL-20240301-001 |
| 报销 | BX | BX-20240301-015 |
| IT工单 | IT | IT-20240301-003 |
| 会议室预订 | HY | HY-20240301-007 |
| 资源预订 | ZY | ZY-20240301-002 |

### 通过编号查询
可直接通过流程编号查询状态：
- "查询流程 QL-20240301-001"
- "IT工单 IT-20240301-003 现在什么状态"

## 五、常见问题FAQ

### Q1: 如何查看我的流程到了哪一步？
**A**: 在OA系统"我的流程"中查看，或直接问Agent"我的请假流程到哪了"，Agent会查询最新状态并告知当前审批节点。

### Q2: 审批人说材料不够，我在哪里补充？
**A**: 在企业微信通知中点击流程卡片，进入详情页后上传补充材料。或直接告诉Agent"帮我给报销单 BX-xxxx 补充发票照片"。

### Q3: 我的流程被驳回了，还能修改吗？
**A**: 可以。查看驳回理由，修改后重新提交。重新提交后作为新流程计算审批时效。

### Q4: 我提交的流程一直没人审批怎么办？
**A**: 可以先催办。超过24小时系统自动催办，超过48小时自动转审给代审人。如仍有问题，联系审批人的上级或HR。

### Q5: 我能看到别人的流程吗？
**A**: 只能看到自己发起的流程和自己负责审批的流程。HR和管理层可查看授权范围内的流程。

### Q6: 提交后发现信息填错了怎么办？
**A**: 如果还在"待审批"状态，可以先撤回再修改重新提交。如果已经有人审批，需联系审批人驳回后修改。
