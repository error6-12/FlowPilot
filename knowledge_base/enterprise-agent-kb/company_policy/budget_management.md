# 预算管理制度

## 一、预算编制

### 1.1 预算编制周期
| 预算类型 | 编制时间 | 审批时间 | 生效时间 |
|---------|---------|---------|---------|
| 年度预算 | 每年10-11月 | 12月 | 次年1月 |
| 季度调整 | 每季度末 | 下季度首月第1周 | 下季度 |
| 临时追加 | 随时 | 提交后5个工作日 | 审批通过日 |

### 1.2 预算编制层级
```
公司总预算 → 事业部预算 → 部门预算 → 项目预算
```

### 1.3 各部门预算编制
| 预算科目 | 负责编制 | 审批人 |
|---------|---------|--------|
| 人力成本 | HR + 各部门 | CFO |
| 差旅费 | 各部门 | 分管VP |
| 办公费用 | 行政部 | CFO |
| IT费用 | IT部 | CTO |
| 营销费用 | 市场部 | CMO |
| 项目费用 | 项目经理 | 分管VP |

## 二、预算执行

### 2.1 预算使用规则
- 所有费用支出须对应预算科目
- 预算使用遵循"先批先用"原则
- 跨科目调拨需财务审批

### 2.2 预算余额查询
- 部门经理：OA → 预算管理 → 查看本部门预算余额
- 项目经理：OA → 项目管理 → 查看项目预算余额
- 财务：可查看全公司预算执行情况

## 三、预算不足时的处理

### 3.1 系统自动检查
所有涉及费用的流程（报销、采购、差旅等）提交时，系统自动检查对应预算科目余额：
- **预算充足**：正常进入审批流程
- **预算不足**：系统弹窗提示，触发以下处理之一

### 3.2 预算不足处理方案
| 情况 | 处理方式 |
|------|---------|
| 预算不足，且金额可调整 | 提示申请人调整金额至预算范围内 |
| 预算不足，需超预算执行 | 触发"超预算审批"（额外审批链路） |
| 预算不足，可延期执行 | 建议推迟至下季度/下月有预算时执行 |
| 预算不足，需追加预算 | 部门负责人提交"预算追加申请" |

### 3.3 超预算审批链路
| 超预算比例 | 审批链路 |
|-----------|---------|
| ≤20% | 部门负责人 → 财务 → VP |
| 20%-50% | 部门负责人 → 财务 → VP → CFO |
| >50% | 部门负责人 → 财务 → VP → CFO → CEO |

### 3.4 预算追加流程
```
部门负责人提交追加申请 → 财务审核 → VP审批 → 追加生效
```
- 追加申请需说明追加原因、金额、使用计划
- 单次追加不超过原预算的30%
- 年度累计追加不超过原预算的50%
- 超过需董事会审批

## 四、预算关联流程

### 4.1 报销关联预算
- 报销提交时自动扣减对应部门/项目的预算
- 报销被驳回或撤回时，预算自动回滚
- 报销审批通过但未付款时，预算为"已冻结"状态
- 付款完成后，预算正式扣减

### 4.2 采购关联预算
- 采购申请提交时自动冻结对应预算
- 采购完成后正式扣减
- 采购取消后预算自动释放

### 4.3 项目关联预算
- 项目立项通过后冻结项目预算
- 项目执行中按里程碑释放预算
- 项目终止后剩余预算释放回公司总池

## 五、预算预警

### 5.1 预警规则
| 预警级别 | 触发条件 | 通知对象 |
|---------|---------|---------|
| 黄色预警 | 预算使用率达到70% | 部门负责人 |
| 橙色预警 | 预算使用率达到85% | 部门负责人 + 财务 |
| 红色预警 | 预算使用率达到95% | 部门负责人 + 财务 + VP |
| 超支通知 | 预算使用率超过100% | 全部相关方 |

### 5.2 预警响应
- 黄色预警：部门负责人关注，控制后续支出
- 橙色预警：部门负责人评估是否需要追加预算
- 红色预警：暂停非必要支出，评估追加预算或调整计划
- 超支：立即暂停该科目所有支出，需VP审批后方可恢复

## 六、常见问题FAQ

### Q1: 报销时系统提示预算不足，怎么办？
**A**: 三个选择：1) 调整报销金额至预算范围内；2) 联系部门负责人申请超预算审批；3) 推迟到下个周期预算释放后再提交。

### Q2: 项目预算可以在不同科目间调剂吗？
**A**: 可以，但需财务审批。同一级别科目间的调剂由财务审批；跨大类科目调剂需VP审批。

### Q3: 部门预算用完了，还有紧急支出怎么办？
**A**: 部门负责人提交"预算追加申请"，说明紧急原因。临时追加审批需5个工作日。极端紧急情况可走紧急采购通道。

### Q4: 项目提前结束，剩余预算怎么处理？
**A**: 项目终止后，剩余预算自动释放回公司总预算池。部门可申请将剩余预算用于其他项目。
