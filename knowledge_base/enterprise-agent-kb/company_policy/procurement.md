# 采购申请管理制度

## 一、适用范围
本制度适用于公司所有采购活动，包括办公设备、软件、服务、项目专项物资等。

## 二、采购分类

| 采购类型 | 说明 | 负责部门 |
|---------|------|---------|
| 办公用品采购 | 日常办公消耗品 | 行政部统一采购 |
| IT设备采购 | 电脑、服务器、网络设备等 | IT部统一采购 |
| 软件采购 | 软件License、SaaS订阅 | IT部统一采购 |
| 项目专项采购 | 项目所需的设备/材料/服务 | 项目所在部门申请 |
| 服务类采购 | 咨询、外包、培训等 | 需求部门申请 |
| 固定资产采购 |  furniture、大型设备等 | 行政部+财务联合管理 |

## 三、金额阈值与审批分级

### 3.1 通用采购审批规则
| 采购金额 | 审批链路 | 备注 |
|---------|---------|------|
| ≤500元 | 直属主管 → 部门负责人 | 小额采购，简化流程 |
| 500-5,000元 | 直属主管 → 部门负责人 → 采购部 | 需采购部比价 |
| 5,000-50,000元 | 直属主管 → 部门负责人 → 采购部 → 财务 | 财务审核预算 |
| 50,000-200,000元 | 直属主管 → 部门负责人 → 采购部 → 财务 → VP | VP审批 |
| >200,000元 | 直属主管 → 部门负责人 → 采购部 → 财务 → VP → CEO | CEO终审 |

### 3.2 IT类采购特殊规则
| 采购金额 | 审批链路 | 备注 |
|---------|---------|------|
| ≤500元 | IT主管 | 日常耗材/配件 |
| 500-5,000元 | IT主管 → IT经理 | 外设/小型设备 |
| 5,000-50,000元 | IT主管 → IT经理 → 采购部 → 财务 | 需技术评估+比价 |
| >50,000元 | IT主管 → IT经理 → 采购部 → 财务 → CTO → VP | 重大IT投资 |

### 3.3 紧急采购
- **适用情形**：设备故障影响业务、客户紧急需求、安全隐患整改
- **审批简化**：可先电话审批，事后24小时内补填OA申请
- **金额上限**：紧急采购单次不超过50,000元
- **审批人**：部门负责人即可批准

## 四、采购申请流程

### 4.1 标准采购流程
```
1. 需求部门提交采购申请（OA）
   ↓
2. 审批流程（按金额分级）
   ↓
3. 采购部执行（比价/招标/下单）
   ↓
4. 到货验收
   ↓
5. 财务付款
```

### 4.2 采购申请必填信息
- 采购物品名称、规格、数量
- 采购原因/用途
- 预算金额
- 期望到货时间
- 推荐供应商（如有）
- 关联项目编号（项目专项采购时必填）

### 4.3 采购部比价要求
| 金额 | 比价要求 |
|------|---------|
| ≤5,000元 | 无需比价，直接采购 |
| 5,000-50,000元 | 至少2家供应商报价 |
| 50,000-200,000元 | 至少3家供应商报价 |
| >200,000元 | 公开招标或邀请招标（≥3家） |

### 4.4 验收流程
- **小额采购**（≤5,000元）：需求部门自行验收
- **中等采购**（5,000-50,000元）：需求部门+采购部联合验收
- **大额采购**（>50,000元）：需求部门+采购部+财务联合验收

## 五、预算关联

### 5.1 预算检查
- 所有采购申请提交时，系统自动检查部门预算余额
- 预算充足 → 正常进入审批流程
- 预算不足 → 系统提示，触发以下操作之一：
  1. 申请人调整采购金额
  2. 部门负责人审批"超预算采购"（需额外说明）
  3. 转财务追加预算审批

### 5.2 超预算采购
- 超预算≤20%：部门负责人+财务审批即可
- 超预算>20%：需VP审批
- 超预算>50%：需CEO审批

## 六、驳回与重新提交

### 6.1 常见驳回原因
- 预算不足且未说明原因
- 缺少比价材料
- 采购物品不在允许范围内
- 数量/金额不合理
- 缺少关联项目编号

### 6.2 重新提交
- 修改后随时可重新提交
- 需在申请中说明针对驳回原因的修改内容
- 审批流程从头开始

## 七、常见问题FAQ

### Q1: 采购申请被驳回了，可以修改金额后重新提交吗？
**A**: 可以。修改金额后重新提交，审批流程按新金额对应的审批链路执行。

### Q2: 项目立项和采购申请如何关联？
**A**: 在采购申请中填写关联的项目编号，系统自动关联。立项通过后，关联的采购申请自动进入审批。

### Q3: 紧急采购怎么操作？
**A**: 先电话向部门负责人请示，获得口头同意后直接采购。事后24小时内在OA补填采购申请，标注"紧急采购"并说明原因。

### Q4: 供应商选择由谁决定？
**A**: 5,000元以下由需求部门推荐；5,000元以上由采购部负责比价和选择，需求部门有建议权。
