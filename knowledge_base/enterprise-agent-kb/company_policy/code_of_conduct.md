# 员工行为规范

## 职业道德

### 1. 诚信原则
- 对公司、客户和同事保持诚实
- 不得伪造数据、报告或工作成果
- 不得虚报考勤、报销或工时
- 不得利用公司资源谋取个人利益

### 2. 保密义务
- 严格保守公司商业机密
- 不得泄露客户信息、技术方案、财务数据
- 离职后仍需遵守保密协议
- 涉密文件按规定存放和传递

### 3. 利益冲突
- 不得在竞争对手或供应商处兼职
- 亲属在竞争公司工作的须主动向HR申报
- 涉及自身利益的决策须回避
- 接受礼品/招待须符合公司标准（不超过500元）

## 工作纪律

### 1. 考勤纪律
- 遵守弹性工作制时间（核心时间10:00-16:00必须在岗）
- 迟到/早退须在企业微信说明
- 请假须提前审批，紧急情况及时补假
- 旷工3天视为自动离职

### 2. 办公秩序
- 保持工位整洁，不存放危险物品
- 办公区域禁止吸烟（可到指定吸烟区）
- 保持安静，不在办公区大声喧哗
- 会议室使用后恢复原状

### 3. 着装要求
- **工作日**：商务休闲装
- **商务场合**：正装（拜访客户、重要会议）
- **禁止穿着**：拖鞋、背心、超短裙（特殊活动除外）
- **周五**：休闲装（Jeans Day）

## 信息安全

### 1. 密码安全
- 密码长度不少于8位，包含大小写字母、数字和特殊字符
- 密码每90天更换一次
- 不同系统使用不同密码
- 不得将密码写在便签纸或共享给他人
- 离开工位须锁屏（Win+L / Cmd+Ctrl+Q）

### 2. 数据保护
- 公司数据不得存储在个人设备或云盘
- 敏感数据传输须加密
- 客户数据使用后及时销毁
- 不得将公司数据上传至未授权的第三方平台

### 3. 设备安全
- 不得私自拆卸或改装公司设备
- 笔记本电脑须安装公司指定的安全软件
- 不得在办公设备上安装盗版软件
- 设备遗失须在1小时内报告IT

### 4. 网络安全
- 不得绕过公司网络安全策略
- 不得私自搭建WiFi热点
- 不得在办公网络进行P2P下载
- 发现网络安全事件立即报告IT

## 商务行为规范

### 1. 客户接待
- 接待客户须提前预约会议室
- 准备充分的会议材料
- 着正装出席商务场合
- 不得在客户面前贬低竞争对手
- 客户拜访后须提交拜访报告

### 2. 商务宴请
- 商务宴请须提前审批
- 标准：人均不超过300元
- 禁止酗酒
- 须保留发票和消费明细
- 宴请后须提交费用报告

### 3. 商务出差
- 出差须提前审批
- 按照差旅标准执行（参见差旅管理制度）
- 出差期间保持通讯畅通
- 出差结束后3个工作日内提交出差报告

## 社交媒体使用

### 1. 个人社交媒体
- 不得在社交媒体泄露公司机密
- 代表公司发言须获得公关部授权
- 不得发布损害公司形象的言论
- 在个人简介中标注"观点仅代表个人"

### 2. 工作社交媒体
- 企业微信/飞书只用于工作沟通
- 不得在群聊中传播不实信息
- 尊重同事，不在群内争吵
- 重要通知以邮件/公告为准

## 反骚扰与反歧视

### 1. 零容忍行为
- 任何形式的性骚扰
- 基于性别、年龄、种族、宗教的歧视
- 职场霸凌和PUA行为
- 恶意造谣和诽谤

### 2. 投诉渠道
- **HR热线**：分机 8800
- **邮箱**：compliance@company.com
- **匿名投诉**：OA系统"合规举报"入口
- 所有投诉严格保密，不得打击报复

### 3. 处理流程
```
投诉提交 → HR受理（24小时内） → 独立调查 → 处理决定 → 结果通知 → 跟踪回访
```

## 常见问题FAQ

### Q1: 可以兼职或做副业吗？
**A**: 不得在竞争对手或供应商处兼职。个人副业如不影响本职工作、不涉及公司利益，需向HR报备获得批准。

### Q2: 收到客户礼品怎么处理？
**A**: 价值500元以下可以接受，超过500元须向HR申报。无法退回的礼品归公司所有。

### Q3: 发现同事违规行为需要举报吗？
**A**: 鼓励通过合规渠道举报。公司有保护举报人的机制，严禁打击报复。

### Q4: 离职后还需要遵守行为规范吗？
**A**: 保密义务和竞业限制（如签署）在离职后继续有效。保密义务无期限，竞业限制最长2年。

### Q5: 工作电脑可以安装私人软件吗？
**A**: 不得安装盗版软件、游戏、P2P下载工具。其他个人软件不影响工作的前提下可以安装，但需通过IT安全检查。
