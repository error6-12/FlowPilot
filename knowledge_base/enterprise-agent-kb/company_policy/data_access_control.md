# 数据权限与敏感信息访问控制

## 一、数据分级

### 1.1 数据敏感等级
| 等级 | 定义 | 示例 |
|------|------|------|
| L1-公开 | 可对外公开的信息 | 公司介绍、公开产品文档、招聘信息 |
| L2-内部 | 公司内部可查看 | 内部通知、组织架构图、一般制度文件 |
| L3-机密 | 限特定部门/岗位查看 | 薪酬数据、财务报表、客户信息、技术方案 |
| L4-绝密 | 限指定人员查看 | 未公开财务数据、核心算法、并购计划、董事会资料 |

## 二、流程表单敏感字段定义

### 2.1 请假流程
| 字段 | 敏感等级 | 可查看角色 |
|------|---------|-----------|
| 请假类型、时间 | L2-内部 | 本人、直属上级、部门经理、HR |
| 请假原因（详细信息） | L3-机密 | 本人、直属上级、审批人 |
| 病假诊断信息 | L4-绝密 | 本人、HR（受隐私保护） |

### 2.2 报销流程
| 字段 | 敏感等级 | 可查看角色 |
|------|---------|-----------|
| 报销类型、金额 | L2-内部 | 本人、各级审批人、财务 |
| 发票照片/明细 | L3-机密 | 本人、各级审批人、财务 |
| 银行卡号 | L4-绝密 | 本人、财务出纳 |
| 个人薪资信息（如超标说明） | L4-绝密 | 本人、财务、VP |

### 2.3 IT工单
| 字段 | 敏感等级 | 可查看角色 |
|------|---------|-----------|
| 故障描述、设备信息 | L2-内部 | 本人、IT工程师 |
| 涉及的系统账号 | L3-机密 | 本人、IT管理员 |
| 涉及的数据/文件内容 | L3-机密 | 本人、IT管理员（受保密约束） |

### 2.4 采购流程
| 字段 | 敏感等级 | 可查看角色 |
|------|---------|-----------|
| 采购物品、数量 | L2-内部 | 本人、各级审批人、采购部 |
| 采购金额、预算信息 | L3-机密 | 本人、各级审批人、财务 |
| 供应商报价明细 | L3-机密 | 采购部、财务、各级审批人 |
| 合同条款 | L4-绝密 | 法务、财务、VP |

## 三、角色权限矩阵

### 3.1 通用权限规则
| 角色 | 权限范围 |
|------|---------|
| 普通员工 | 仅查看自己发起/参与的流程 |
| 直属上级 | 查看下属的流程 + 自己负责审批的流程 |
| 部门经理 | 查看本部门所有流程 |
| HR | 查看所有HR相关流程（请假、调岗、离职等） |
| 财务 | 查看所有财务相关流程（报销、采购、预算等） |
| IT | 查看所有IT工单 |
| 行政 | 查看所有行政相关流程（会议室、办公用品等） |
| VP | 查看分管部门所有流程 |
| CEO | 查看所有流程 |
| Agent运营 | 查看流程日志（不含敏感字段内容） |

### 3.2 敏感字段脱敏规则
| 场景 | 脱敏方式 |
|------|---------|
| 列表页展示 | 金额显示为"****"，银行卡号显示为"****1234" |
| 统计报表 | 使用脱敏后的聚合数据 |
| 导出文件 | 敏感字段自动脱敏 |
| Agent回复 | 不展示敏感字段的原始值 |

## 四、访问控制机制

### 4.1 技术措施
- **角色基访问控制（RBAC）**：按角色分配功能权限
- **数据行级控制**：按部门/团队限定数据可见范围
- **字段级控制**：敏感字段按角色脱敏或隐藏
- **操作审计**：所有数据访问行为记录审计日志

### 4.2 权限申请
- 需要超出默认权限的访问，在OA提交"数据权限申请"
- 填写申请原因和所需权限范围
- 数据Owner审批
- IT配置权限，有效期默认30天

### 4.3 权限回收
- 临时权限到期自动回收
- 员工调岗/离职时自动清理权限
- 定期审计异常权限（每季度一次）

## 五、违规处理

| 违规行为 | 处理方式 |
|---------|---------|
| 越权查看（非主观故意） | 警告 + 权限回收 |
| 越权查看（主观故意） | 严重警告 + 降级 |
| 泄露敏感信息 | 解除劳动合同 + 追究法律责任 |
| 分享账号给他人 | 严重警告 + 账号锁定 |

## 六、常见问题FAQ

### Q1: 我想查看其他部门的流程，怎么申请？
**A**: 在OA提交"数据权限申请"，说明查看原因和需要的范围，经数据Owner（对方部门负责人）审批后开通临时权限。

### Q2: Agent能看到我提交的敏感信息吗？
**A**: Agent可以读取流程内容以提供智能服务，但Agent的日志中敏感字段会脱敏处理。Agent运营人员无法通过日志查看原始敏感信息。

### Q3: 离职后我的流程记录会被删除吗？
**A**: 不会删除。流程记录按归档制度保留，但你的个人账号会被注销，后续无法登录查看。
