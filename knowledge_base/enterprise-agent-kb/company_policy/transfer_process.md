# 员工调岗与项目移交管理流程

## 一、内部调岗

### 1.1 调岗条件
- 在当前岗位工作满1年
- 最近4个季度绩效B+及以上
- 无违纪记录
- 接收部门有岗位空缺

### 1.2 调岗申请流程
```
员工提交调岗申请 → 现任领导审批 → 接收部门面试 → 接收部门审批 → HR审核 → 调岗生效
```

| 环节 | 时限 | 说明 |
|------|------|------|
| 现任领导审批 | 3个工作日 | 评估是否影响当前工作 |
| 接收部门面试 | 5个工作日 | 确认岗位匹配度 |
| 接收部门审批 | 2个工作日 | 确认录用意向 |
| HR审核 | 2个工作日 | 审核条件、协调薪资 |
| 过渡期 | 视情况 | 通常2-4周工作交接 |

### 1.3 薪资调整
- 调岗后薪资按目标岗位标准执行
- 就高不就低：新岗位薪资下限低于原薪资的，保持原薪资不变
- 就高原则：新岗位薪资标准更高的，按新标准执行

## 二、项目移交流程

### 2.1 触发情形
- 员工调岗/离职
- 项目组织架构调整
- 员工长期请假（>30天）

### 2.2 移交清单
| 移交类别 | 具体内容 | 责任人 |
|---------|---------|--------|
| 文档资料 | 项目文档、设计文档、技术方案、会议纪要 | 移交人 |
| 代码资产 | 代码仓库权限、开发分支、未合并的代码 | 移交人+技术Lead |
| 账号权限 | 系统账号、管理后台权限、第三方服务账号 | 移交人+IT |
| 客户关系 | 客户联系方式、沟通记录、未关闭的需求 | 移交人 |
| 实物资产 | 设备、钥匙、门禁卡等 | 移交人+行政 |
| 待办事项 | 未完成的任务清单、截止日期、阻塞项 | 移交人 |
| 知识库 | 个人笔记、技术文档、经验总结 | 移交人 |

### 2.3 移交流程
```
1. 移交人填写《项目移交清单》
   ↓
2. 交接双方逐项确认移交内容
   ↓
3. 接收人确认接收
   ↓
4. 项目经理/主管审核确认
   ↓
5. HR备案
```

### 2.4 移交时限
| 情形 | 移交时限 |
|------|---------|
| 内部调岗 | 调岗生效后2周内完成 |
| 离职 | 最后工作日前完成 |
| 长期请假 | 请假开始前完成 |

## 三、人员异动流程联动

### 3.1 调岗触发的人员异动流程
调岗申请通过后，系统自动触发以下联动：

| 联动流程 | 触发时机 | 自动操作 |
|---------|---------|---------|
| 考勤变更 | 调岗生效日 | 考勤组自动切换至新部门 |
| 汇报关系变更 | 调岗生效日 | 组织架构中更新直属上级 |
| 薪资调整 | 调岗生效日 | HR更新薪资记录 |
| 权限变更 | 调岗生效日 | IT调整系统权限 |
| 项目移交 | 调岗审批通过后 | 系统通知项目经理启动移交 |
| 培训安排 | 调岗生效后1周内 | HR安排新岗位培训 |

### 3.2 需要同步的材料
| 同步对象 | 所需材料 |
|---------|---------|
| 新部门 | 调岗审批单、岗位说明书 |
| IT部门 | 权限变更申请表 |
| 行政部 | 工位变更通知 |
| HR | 调岗审批单、薪资调整确认书 |
| 项目经理 | 项目移交清单 |
| 财务 | 成本中心变更通知 |

### 3.3 离职触发的人员异动
| 联动流程 | 触发时机 | 自动操作 |
|---------|---------|---------|
| 项目移交 | 离职申请通过后 | 通知项目经理启动移交 |
| 账号注销 | 最后工作日 | IT注销所有系统账号 |
| 资产清退 | 最后工作日前 | 行政核查资产归还 |
| 薪资结算 | 最后工作日 | 财务结算工资、报销、借款 |
| 社保公积金 | 次月 | HR办理社保转移 |

## 四、常见问题FAQ

### Q1: 调岗后原来的项目怎么办？
**A**: 调岗审批通过后，系统会自动通知项目经理启动项目移交。移交清单需逐项确认，项目经理审核通过后调岗才能最终生效。

### Q2: 调岗需要重新签合同吗？
**A**: 如果岗位变更涉及劳动合同条款变化（如工作地点变更），需要签订补充协议。岗位和部门变更一般只需签订调岗确认书。

### Q3: 调岗申请被现任领导拒绝怎么办？
**A**: 可与现任领导沟通协商。如沟通无效，可向HR申请协调。HR会综合评估双方意见后给出建议。

### Q4: 移交过程中发现遗漏怎么办？
**A**: 移交清单确认前可随时补充。移交完成后发现遗漏，由移交人配合补充。离职后发现的遗漏，由项目经理协调处理。
